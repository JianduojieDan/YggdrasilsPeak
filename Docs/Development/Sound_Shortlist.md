# Sound shortlist (first pass, nothing downloaded yet)

The game must ship on Steam, so every sound needs a licence that allows commercial use. Check the licence on each sound's own page and record it here when choosing. Downloads go to the project's `Downloads/`, never C:.

## Sources found

| Source | Licence as found | Use |
|---|---|---|
| [BigSoundBank](https://bigsoundbank.com/vent-fort-1-s0146.html) | CC0 listed on its pages; check each sound | Wind, weather |
| [Kenney UI Audio](https://www.kenney.nl/assets/ui-audio) | CC0 | Wheel clicks; 50 UI sounds, a ratchet is not confirmed |
| [Mixkit storm](https://mixkit.co/free-sound-effects/storm/) / [wind](https://mixkit.co/free-sound-effects/wind) | Own Mixkit licence: read before use | Blizzard, thunder |
| [Gregor Quendel thunder ambience](https://gregor-quendel.itch.io/free-thunder-lightning-ambience) | Not stated in search result: confirm on page | Thunder |
| Freesound: [Tim Kahn mountain wind](https://freesound.org/people/tim.kahn/sounds/253899), [daveincamas blizzard](https://freesound.org/people/daveincamas/sounds/558664) | Not confirmed; varies per sound | Mountain wind, storm |

Not confirmed yet: the Sonniss GDC bundle (widely used for games; its licence terms still need reading).
